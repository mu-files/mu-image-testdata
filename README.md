# mu-image Test Data

This repository contains test data files for the [mu-image](https://github.com/mu-files/mu-image) project.

## Contents

- DNG files: Raw image test files
- JXL files: JPEG XL compressed test files
- CSV/XLSX files: Test parameter lists

## Usage

This repository is automatically cloned by the mu-image test suite when running tests.
You don't need to clone it manually unless you're adding new test data.
